# Enthusiast Domain Common

E-commerce contracts for the Enthusiast domain definition for [Suvereo](https://github.com/upsidelab/suvereo).

This package contains the plugin interfaces (`ProductSourcePlugin`, `DocumentSourcePlugin`, `ECommerceIntegrationPlugin`, `ECommercePlatformConnector`), shared data structures (`ProductDetails`, `DocumentDetails`, `Address`, ...) and evaluation helpers. It has no Django dependency, so source plugins that build on it stay lightweight.

## Installing

```commandline
poetry add enthusiast-domain-common
```
